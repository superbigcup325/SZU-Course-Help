## 无需 Python，完整解压后即可使用

本版本提供 Windows、macOS 和 Linux 原生发布包。普通用户请下载与自己系统匹配的 ZIP，不要下载 GitHub 自动附带的 Source code 压缩包。

## v3.6.1 更新说明

1. 爆发模式转一般模式、一般模式转扫描模式的业务失败阈值可以独立填写，有限值范围为 1 至 1,000,000 次。
2. 两级阈值均可分别选择“无限次”，关闭对应模式的业务失败自动降级；默认行为仍为 5 次转一般、累计 10 次转扫描。
3. 页面实时显示当前阈值，刷新后从后台恢复。网络异常与学校 5xx 响应不计入业务失败，程序重启后阈值恢复默认值。
4. Release 运行数据位于系统用户目录，升级后继续使用原有清单、Card Key 身份和安全课程缓存。迁移不会覆盖已有目标文件；发现多个旧目录时会要求选择。
5. 任务安全暂停后可以新增、移除、重新排队、开关课程以及调整优选分组和组内优先级；继续前与每轮请求前都会重新读取 SQLite。
6. 支持明确停止任务，并覆盖最后一门课程被移除、暂停尚未停稳、重复加入、多页面编辑和失败课程重试等边界。
7. 保留已选、待选与合计学分统计、只读周课表、多时段与单双周解析、长课程名称完整换行及冲突时段提示。
8. WebVPN 只作为认证后的只读查询备用入口。选课提交固定使用学校主站，不跨后端重试；本版不提供自动退课。
9. OCR 自动重登录兼容 `ddddocr 1.6.1` 的多种 API；CI 覆盖 Python 3.13/3.14，四个平台构建前均真实初始化 OCR。
10. 完整目录缓存按学号摘要、批次、校区和课程类型隔离；未登录或非开放期只读取当前终端学号的本地缓存。
11. 学校密码只保存在当前 Python 进程内存中；不保存浏览器密码、磁盘会话或持久化受控浏览器配置。
12. 保留多校区目录、完整搜索、阶段白名单、50 张 OCR 验证码上限、200 次连续未知响应保护和可见自动重登录状态。
13. 自动测试全部使用假数据，不访问学校，也不执行选课或退课操作。
14. Release 只提供各平台与源码 ZIP，不附带独立 `.sha256` 或 `SHA256SUMS.txt` 文件。

## 首次运行

1. 完整解压 ZIP，不要在压缩包预览窗口内直接运行，也不要只拖出主程序。
2. 运行平台启动脚本，在终端输入学号并生成本机 Card Key。
3. 输入 `Y` 后，程序会启动本地网页并打开登录页。
4. 首次登录由用户输入学校密码并手动完成点击验证码。
5. 预选、未开放、已结束和未知阶段禁止启动自动选课；只有学校返回明确允许的复选、正选、补选或补退选批次才可在二次确认后启动。

## 数据与安全

- Windows 数据目录：`%APPDATA%\SZU-Course-Help\`。
- macOS 数据目录：`~/Library/Application Support/SZU-Course-Help/`。
- Linux 数据目录：`${XDG_DATA_HOME:-~/.local/share}/SZU-Course-Help/`。
- 学校密码、token 与 Cookie 不写入磁盘；关闭程序后必须重新手动登录。
- 当前版本未购买 Windows 或 Apple 商业代码签名证书，SmartScreen 或 Gatekeeper 可能显示未知开发者提示。
- 只从本仓库官方 Release 下载，不要运行群文件、网盘或陌生链接中的副本。
- 学校接口和规则可能变化，关键选课结果以学校官方系统为准。

完整步骤、任务暂停编辑、数据迁移、自动重登录和常见问题请阅读发布包中的 `使用手册.pdf`。
