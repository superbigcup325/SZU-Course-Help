## 无需 Python，完整解压后即可使用

本版本提供 Windows、macOS 和 Linux 原生发布包。普通用户请下载与自己系统匹配的 ZIP，不要下载 GitHub 自动附带的 Source code 压缩包。

## v3.6.0 更新说明

1. Release 运行数据迁移到系统用户目录，升级后继续使用原有清单、Card Key 身份和安全课程缓存。首次启动仅复制经过校验的数据，绝不覆盖已有目标文件；发现多个旧目录时会要求选择。
2. 任务显示“已暂停”后可以新增、移除、重新排队、开关课程以及调整优选分组和组内优先级；继续前与每轮请求前都会重新读取 SQLite，历史尝试次数不会丢失。
3. 新增“停止抢课”并完善最后一门课程被移除、暂停请求尚未停稳、重复加入、多个页面同时编辑及失败课程重试等边界。
4. 修复新课程排名都为零导致上下移动无效的问题；优先级只改变尝试顺序，程序不会自动退选、替换或升级任何课程。
5. 新增已选学分、待选学分和合计学分展示，保留只读周课表、多时段与单双周解析、长课程名称完整换行以及冲突时段提示。
6. WebVPN 仅作为认证后的只读查询备用入口。自动选课提交固定使用学校主站，不会因查询回退而改走 WebVPN，也不会跨后端重试；本版不提供自动退课。
7. OCR 自动重登录继续支持 `ddddocr 1.6.1` 的多种 API 布局；CI 覆盖 Python 3.13/3.14，四个平台的 Release 构建均在打包前真实初始化 OCR。
8. 完整目录缓存按学号摘要、批次、校区和课程类型隔离；未登录或非开放期只能读取当前终端学号的本地只读缓存，不会混用其他账号数据。
9. 移除同源学校反向代理、浏览器密码保存、磁盘会话恢复、POST 故障切换、自动退选升级和强制依赖镜像。学校密码始终只保存在当前 Python 进程内存中。
10. 本版本经安全审查后重写整合 PR #7 的可用功能，并完成 Issue #6 与 #8；自动测试全部使用假数据，不访问学校或执行选课、退课操作。
11. 保留多校区目录、缓存模式、完整搜索、阶段白名单、50 张 OCR 验证码上限、200 次连续未知响应保护与可见自动重登录状态。
12. Release 只提供各平台与源码 ZIP，不附带独立 `.sha256` 或 `SHA256SUMS.txt` 文件。

## 首次运行

1. 完整解压 ZIP，不要在压缩包预览窗口内直接运行，也不要只拖出主程序。
2. 运行平台启动脚本，在终端输入学号并生成本机 Card Key。
3. 输入 `Y` 后，程序会启动本地网页并打开登录页。
4. 首次登录由用户输入学校密码并手动完成点击验证码。
5. 预选、未开放、已结束和未知阶段禁止启动自动选课；只有学校返回明确允许的复选、正选、补选或补退选批次才可在二次确认后启动。

## 数据与安全

- Windows 数据目录：`%APPDATA%\SZU-Course-Help\`。
- macOS 数据目录：`~/Library/Application Support/SZU-Course-Help/`。
- Linux 数据目录：`${XDG_DATA_HOME:-~/.local/share}/SZU-Course-Help/`。
- 学校密码、token 与 Cookie 不写入磁盘；关闭程序后必须重新手动登录。
- 当前版本未购买 Windows 或 Apple 商业代码签名证书，SmartScreen 或 Gatekeeper 可能显示未知开发者提示。
- 只从本仓库官方 Release 下载，不要运行群文件、网盘或陌生链接中的副本。
- 学校接口和规则可能变化，关键选课结果以学校官方系统为准。

完整步骤、任务暂停编辑、数据迁移、自动重登录和常见问题请阅读发布包中的 `使用手册.pdf`。
